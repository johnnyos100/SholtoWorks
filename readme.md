# SWTT Token — SholtoWorks Time Token

Official token repository for **SholtoWorks Time Token (SWTT)** on Base (Chain ID 8453).

This repository makes SWTT discoverable by wallets, DEXes, and token registries including Coinbase Wallet, MetaMask, Trust Wallet, Rainbow, Uniswap, Aerodrome, and CoinGecko.
